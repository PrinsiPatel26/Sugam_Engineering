# Sugam Engineering - Automotive Component Finder

A modern web platform for SUGAM ENGINEERING to showcase automotive components and provide a vehicle application finder.

## Features

- **Vehicle Application Finder**: Find exact parts for your vehicle (Brand → Model → Part)
- **Product Catalog**: Browse brake discs, brake drums, and wheel hubs
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Premium UI**: Modern automotive-themed interface with smooth animations
- **Inquiry System**: Direct inquiry and WhatsApp contact options

## Tech Stack

- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- Vite
- React Router
